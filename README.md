# Apekshya Basnyat - Django Portfolio

A personal portfolio website built with Django to showcase my skills, projects, academic background, and professional interests.

> 🚧 **This portfolio is currently under development.**
>
> I am continuously improving the design, adding projects, and working on new features as I learn and develop my Django and web development skills.

## About the Project

This portfolio is being developed using Django as a practical project to strengthen my understanding of web development, databases, forms, Django Admin, static files, and deployment.

The website will showcase my academic journey, technical skills, projects, and ways to connect with me.

## Current Features

- Personal introduction
- About Me section
- Skills section
- Dynamic project section using Django models
- Django Admin panel
- Contact form
- Contact messages stored in the database
- Responsive styling
- Static file management with WhiteNoise
- Gunicorn deployment configuration
- Git and GitHub version control

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git
- GitHub
- WhiteNoise
- Gunicorn
